## NPC 跳跃计算

在项目根目录运行以下命令，按提示逐项输入。所有数值都支持用 `.` 或 `。` 作小数点，例如 `3.8` 和 `3。8` 等效。

```sh
yarn jump
```

先填水平起跳速度，再填向上起跳速度，两项都只取大小，单位为像素/tick。粘性辐射尘普通跳跃依次填 `3.8` 和 `8`，直接粘贴游戏里的 `-3.8` 和 `-8` 也会得到相同结果。原地跳时水平速度填 `0`。在环境和自定义参数两题直接回车，即可按普通空气环境计算。要模拟水中跳跃，环境选 `2`。在自定义参数一题输入 `y`，可设置重力、下落限速、水平加速度、前后摇和观测时长。

起跳前和落地后分别等待多少帧可以用 `--pre-jump-ticks 20 --post-landing-ticks 25` 设置，两项默认都是 0。等待时角色原地停留。腾空平均 X 速度按腾空时间计算，含前后摇的平均 X 速度按总耗时计算。任一等待帧数大于 0 时显示两项。后摇从落地后开始计时，使用 `--ticks 20` 可查看起跳后最多 20 tick 的轨迹。

默认按普通 NPC 在平地上起跳计算，重力为 0.3 px/tick²，下落限速为 10 px/tick。速度表并列显示 px/tick、px/s 和约合的格/s（每秒 60 tick，每格 16 px）。距离表列出相对起点的最远水平距离和最大上升高度，单位为像素和格。环境预设和自定义参数见 `yarn jump --help`。
