# 原版 Boss 数值对照表

泰拉瑞亚 1.4.4.9 / tModLoader，和[速度对照表](速度对照表.md)使用同一版本。收录 8 个困难模式前 Boss、10 个困难模式 Boss、14 类事件 Boss 和 Zenith 种子的机械美杜莎。 [Boss 名录（1.4.4 时期快照）](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Bosses)

- 三个数值依次为 **经典 / 专家 / 大师**。单个数值表示三个难度相同，`—` 表示该难度或该栏不适用。

- 主表按普通种子、单人、Boss 所在进度整理。专家和大师的多人生命缩放按 NPC 类型分别计算，一些事件也有独立的缩放规则。 [专家模式](https://terraria.wiki.gg/wiki/Expert_Mode) · [大师模式](https://terraria.wiki.gg/wiki/Master_Mode)

- 接触与招式伤害是应用玩家防御、减伤等结算前的数值。按部位标明独立或共享生命池，阶段变化和免伤条件见表后。

- 基础数值取自本机 `tModLoader.dll` 的 `NPC.SetDefaults` 和难度缩放，阶段与特殊状态对照同版本 AI。NPC ID 可用 `NPCID` 查询。 [tModLoader NPC](https://docs.tmodloader.net/docs/stable/class_n_p_c.html) · [NPC ID](https://docs.tmodloader.net/docs/stable/class_n_p_c_i_d.html)

### 阶段、部位与代表性攻击

- **史莱姆王**受伤时会召出蓝史莱姆。专家和大师有概率改为尖刺史莱姆（NPC 535，最大生命 — / 100 / 150，接触伤害 — / 28 / 42，防御 5）。 [史莱姆王](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/King_Slime)

- **克苏鲁之眼**在生命低于 50% / 65% / 65% 时转入二阶段。专家和大师二阶段在生命低于 12% 时防御降至 -15，低于 4% 时降至 -30，接触伤害同时升至 40 / 60。 [克苏鲁之眼](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Eye_of_Cthulhu)

- **世界吞噬怪**初始有 67 / 72 / 72 节，逐节独立扣血，初始合计 10,050 / 15,120 / 19,224。中间体节被打掉时会断成两截。专家和大师的邪恶唾液是 NPC 666，AI 中的接触伤害为 64 / 96。 [世界吞噬怪](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Eater_of_Worlds)

- **克苏鲁之脑**一阶段本体无敌，先清掉 20 只飞眼怪才可伤到本体。按飞眼怪与本体合计，本场需打掉 3,250 / 5,525 / 7,029 生命。 [克苏鲁之脑](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Brain_of_Cthulhu) · [1.4.4 更新记录](https://terraria.wiki.gg/wiki/Desktop_1.4.4)

- **蜂王**的毒刺伤害为 22 / 44 / 66。专家和大师防御随失血增加，按照已损失生命比例乘 20 后向下取整，再加 8，存活时最高 27。 [蜂王](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Queen_Bee)

- **骷髅王**的头在专家和大师每有一只手存活加 25 防御，头部旋转时各难度均减 10 防御，旋转接触伤害为 32 / 91 / 136。专家和大师的追踪骷髅头伤害为 68 / 102。黎明狂暴时头的接触伤害为 1,000，防御为 9,999。 [骷髅王](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Skeletron)

- **鹿角怪**的冰刺、飞石、暗影之手伤害分别为 26 / 52 / 78、36 / 72 / 108、20 / 40 / 60。目标与其中心的距离持续 30 tick 不小于 450 px 时会进入无敌。 [独眼巨鹿](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Deerclops)

- **血肉墙**的两只眼和嘴共用一条生命，眼部防御更低。眼睛激光随生命下降而加强，伤害为 22–30 / 44–60 / 66–90。血肉墙生命降到 75% 和 50% 以下时，连接状态的饿鬼接触伤害分别升至 45 / 90 / 135 和 60 / 120 / 180。经典难度的防御也依次升至 20、30，专家和大师维持 16。 [血肉墙](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Wall_of_Flesh)

### 阶段、部位与代表性攻击

- **史莱姆皇后**在生命降至 50% 后开始飞行，两阶段接触伤害和防御相同。皇后粉碎 80 / 160 / 240，皇家凝胶 60 / 120 / 180。 [史莱姆皇后](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Queen_Slime)

- **双子魔眼**各自降到 40% 以下时变身，两个生命池合计 43,000 / 64,500 / 82,237。激光眼普通激光 40 / 76 / 114，变身后死亡激光 50 / 92 / 138，连射时 36 / 68 / 102。魔焰眼的诅咒焰弹 50 / 88 / 132，变身后喷火 60 / 108 / 162。 [双子魔眼](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/The_Twins)

- **毁灭者**有 82 节，头、体节和尾共用一个生命池。体节死亡激光 44 / 72 / 108，探测怪粉色激光 50 / 88 / 132。 [毁灭者](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/The_Destroyer) · [探测怪](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Probe)

- **机械骷髅王**击破头部即可结束战斗。机械炮炸弹 80 / 160 / 240，机械激光 50 / 100 / 150。 [机械骷髅王](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Skeletron_Prime)

- **世纪之花**在生命降至 50% 时变身。第一阶段种子 44 / 76 / 114、毒种子 54 / 96 / 144、刺球 62 / 108 / 162。离开地下丛林时本体接触伤害翻倍，一、二阶段防御分别变为 72 和 40。 [世纪之花](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Plantera)

- **石巨人**先击破附着的头，再击破躯体。头和躯体合计 40,000 / 60,000 / 76,499，双拳为可选目标。附着的头在生命低于一半时，火球从 36 / 72 / 108 增至 48 / 96 / 144，并发射 56 / 112 / 168 的眼部光束。 [石巨人](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Golem)

- **猪龙鱼公爵**在 50% 生命进入二阶段，专家和大师在 15% 生命进入三阶段。鲨鱼旋风 80 / 100 / 150，二阶段的克苏鲁旋风 160 / 200 / 300。 [猪龙鱼公爵](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Duke_Fishron)

- **光之女皇**在生命降至 50% 后切换攻击顺序。夜间七彩矢由 90 / 120 / 180 提高至 100 / 140 / 210，太阳舞由 100 / 140 / 210 提高至 120 / 160 / 240。日间暴怒时接触伤害设为 9,999，弹幕也会进入高伤害状态。 [光之女皇](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Empress_of_Light)

- **拜月教邪教徒**在生命降至 50% 时防御从 42 降至 27。冰雪雾 70 / 100 / 150，火光球 60 / 80 / 120，闪电珠 90 / 120 / 180。仪式中命中幻影或未能打断仪式会召出援军。 [拜月教邪教徒](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Lunatic_Cultist)

- **月亮领主**三只眼和核心共有四个独立生命池，合计 145,000 / 217,500 / 277,311。眼睛睁开时可攻击，三只眼被击破后核心开放，每只眼会放出一只无敌的克苏鲁真眼。额眼幻影致命光 150 / 300 / 450，克苏鲁真眼版本 100 / 200 / 300。 [月亮领主](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/Moon_Lord) · [克苏鲁真眼](https://wiki.ronlab.site/content/terrariawiki_en_2025-10/True_Eye_of_Cthulhu)
