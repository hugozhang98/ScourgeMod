# 数据同步

`Helper/SyncHelper.cs` 负责自定义数据包的编码、收发和消息分发，模组入口已接入 `HandlePacket`，卸载时会清空注册的处理器。

## 发送方向

```csharp
// 客户端发送给服务器。多个参数会按顺序写入数据包。
SyncHelper.SendToServer(messageId, NPC.whoAmI);

// 服务器广播给所有客户端。
SyncHelper.SendToClients(messageId, [playerIndex, cooldown]);

// 服务器发送给指定客户端。
SyncHelper.SendToClients(messageId, [playerIndex, cooldown], toClient: playerIndex);

// 服务器广播时排除一个客户端。
SyncHelper.SendToClients(messageId, [playerIndex, cooldown], ignoreClient: playerIndex);
```

这两个方法仅在对应的网络模式下发送，发送后返回 `true`，其他模式返回 `false`。单机直接执行业务逻辑。

## 注册处理器

每种消息使用一个唯一的 `byte` 编号，在 `Mod.Load` 或相关 `ModSystem.Load` 中注册一次。可以只提供一个方向的处理器；重复注册会报错。

```csharp
private const byte NpcHitPlayerMessage = 0;

public override void Load()
{
    SyncHelper.RegisterHandler(
        NpcHitPlayerMessage,
        serverHandler: (data, sender) =>
        {
            if (!Main.player[sender].active)
                return;

            // 先检查业务字段的数量、类型和取值。
            if (data is not [int npcIndex])
                return;

            if (npcIndex < 0 || npcIndex >= Main.maxNPCs)
                return;

            NPC npc = Main.npc[npcIndex];
            if (!npc.active)
                return;

            // 继续检查 NPC 类型及业务条件，然后更新服务器上的状态。
            // sender 是框架提供的发包玩家编号，不需要客户端再传玩家编号。
        }
    );
}
```

`serverHandler` 接收客户端请求，`clientHandler` 接收服务器同步。服务器收到包时会先检查发送者编号；处理器负责校验玩家状态、数据和业务条件。工具不统一要求玩家已激活，以兼容加入世界时的同步；致死命中也需要处理，因此命中上报不应简单排除已经死亡的玩家。

接收端不会自动转发。需要同步给其他玩家时，在服务器处理器校验并更新状态后，再调用 `SendToClients`。转发后客户端处理器收到的发送者编号是服务器编号；需要知道原玩家时，服务器应将该玩家编号写进下发的数据。

对于 Boss 的连续未命中计数：受击客户端在 `OnHitPlayer` 中上报 NPC 编号，服务器处理器验证 NPC 类型后清零；每帧递增仍放在服务器 AI 中。客户端需要显示计数时，再通过 `SendExtraAI` 同步。

## 数据格式与边界

- 支持 `int`、`float`、`string`、`bool`、`double`、`long`、`short`、`byte`、`uint`，不支持 `null` 或自定义对象。新增结构应拆成基础字段，或另写专用数据包。
- 收发两端必须约定相同的字段顺序和类型。例如 `(short)NPC.whoAmI` 接收后是 `short`，不会自动变成 `int`。
- 数据格式为：消息编号 `byte`、字段数量 `int`、每个字段的类型标记 `byte` 和字段值。保留旧 `SyncUtil` 的九种基础类型编号。
- 每包最多 256 个字段，发送时还会检查框架允许的数据包总长度。非法字段数量、未知类型、截断内容会在收包入口被记录并丢弃；处理器自身的异常正常抛出，方便调试。
- `WritePacket` / `ReceivePacket` 可用于独立的编码和解码；正常联网使用发送方法和已接入的 `HandlePacket` 即可。
